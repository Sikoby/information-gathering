# Briefing: Data Warehouse Requirements Interview

Conduct a data warehouse requirements interview covering:
- Source systems (which apps, which databases, which APIs)
- Data volumes (rough TB, growth rate)
- Refresh frequency expectations per domain
- BI tools currently in use
- Cloud provider preferences and constraints
- Compliance (GDPR, SOC2, industry-specific)

Aim for 30 minutes. End with a confirmation of the top three priorities.
